# Developer Portfolio & Project Showcase

This repository contains the source code and media assets for my personal developer portfolio and software engineering hub. It serves as a centralized platform to showcase my technical engineering projects, game development builds, and core programming capabilities.

🌐 **[Visit the Live Portfolio](https://mariusvalentin189.github.io/personal-portfolio/)**

---

## 🕹️ Core Highlights & Portfolio Structure

The site architecture is optimized for rapid review by technical recruiters and studio hiring managers, separating my work into clear, filterable sections:

* **Game Development**: Showcases of playable builds, gameplay mechanics, and engine implementations (Unity/Unreal).
* **Software Engineering**: Repositories highlighting system architecture, tools, and technical programming solutions.
* **Technical Stack**: A visual dashboard of languages, frameworks, and developer tools I utilize daily.
* **Engineering Blog**: Articles and deep-dives detailing complex optimizations, graphics pipelines, or code architecture solutions.

## 🛠️ Technical Implementation

The portfolio leverages modern static-site technology to deliver ultra-fast load times, clean code structures, and responsive layouts across all device types.

* **Static Site Generator**: [Hugo](https://gohugo.io)
* **Design Framework**: [Hugo Blox Builder](https://hugoblox.com) (Developer Portfolio Theme)
* **Theme Styling**: Dark-mode primary architecture for a sleek, technical aesthetic.
* **Hosting & Deployment**: Automated continuous integration via [GitHub Pages](https://github.com).
